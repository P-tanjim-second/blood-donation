# Give Another Chance

A dedicated platform connecting individuals who urgently need blood with willing and compatible donors in their area. 

### 🌐 Live Link
[Give Another Chance](https://give-another-chance.vercel.app/)

## Purpose
The primary goal of this platform is to bridge the gap between blood donors and recipients. During medical emergencies, finding a matching blood group quickly is a matter of life and death. This application streamlines the process by allowing users to search for active donors by location and blood group, create urgent public requests, and manage donation lifecycles efficiently through a central dashboard.

## Key Features
- **Donor Search:** Quickly filter and find available donors based on blood group, district, and upazila.
- **Urgent Requests:** Create public donation requests with precise hospital details and required deadlines.
- **User Dashboards:** Dedicated profiles for Donors, Volunteers, and Admins to manage their activities and track statuses.
- **Secure Authentication:** JWT-based session management ensuring secure access to protected routes.
- **Responsive UI:** Clean, accessible, and fast interface built for both desktop and mobile devices.

## Tech Stack & Packages Used
This project is built using modern web technologies to ensure speed and reliability:
- **Next.js** - Core framework for server actions, server-side rendering, and routing.
- **Better Auth** - Secure authentication, JWT session handling, and MongoDB adapters.
- **MongoDB** - Native Node.js driver for direct, high-performance database interactions.
- **Tailwind CSS** - Utility-first styling for custom designs.
- **HeroUI** - Accessible and customizable React UI components.
- **Framer Motion** - Smooth, interactive micro-animations and transitions.
- **React Hot Toast** - Lightweight toast notifications for real-time user feedback.
